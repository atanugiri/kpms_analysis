# KPMS Analysis (Notebook-First)

This repo uses notebooks for setup, comparison, visualization, and statistics, with HPC scripts for model training/fitting.

Primary workflow:

1. Run `notebooks/01_project_setup.ipynb`.
2. Train/fit models on HPC using scripts in `hpc/`.
3. Compare model results with `notebooks/02_model_fitting.ipynb`.
4. Run `notebooks/03_visualization.ipynb`.
5. Run `notebooks/04_statistical_analysis.ipynb`.
